# Rajraani Admin Suite: Design Documentation

## Project Vision
**Ethos & Elegance**
A high-fidelity administrative command center for a luxury heritage brand. The suite balances the functional requirements of enterprise data management with the sophisticated aesthetic of high-end fashion and jewelry.

---

## Design System: "Ethos & Elegance"

### Visual Identity
- **Primary Palette:** Deep Charcoal (#1a1a1a) and Royal Gold accents.
- **Surface Strategy:** "Surface-on-Surface" approach using off-white elevations (#fbf9f8) and layered shadows to create depth without visual clutter.
- **Typography:** 
  - **Headings:** *Playfair Display* (Classical, prestigious, high-contrast serif).
  - **Interface/Data:** *Inter* (Clean, legible sans-serif for high-density information).

### Design Tokens
- **Roundness:** Subtle (ROUND_FOUR) for a structured, professional feel.
- **Effects:** Glassmorphic navigation, subtle grain textures, and "floating" interactive states.

---

## Core Modules

### 1. Executive Overview
**The Strategic Command Center**
- **Purpose:** Real-time visibility into revenue, audience growth, and platform health.
- **Key Features:** Sophisticated KPI cards, cumulative revenue trend visualizations, and a live activity feed for operational awareness.

### 2. Order Vault (Order Management)
**Precision Transaction Tracking**
- **Purpose:** Manage high-value heritage acquisitions with a focus on provenance and white-glove fulfillment.
- **Key Features:** Multi-currency support (INR, GBP, AED), custom status badges (Processing, Shipped, Delivered), and collection-line filtering.

### 3. Curated Catalog (Product Management)
**The Digital Gallery**
- **Purpose:** Treat inventory management with the reverence of a gallery exhibit.
- **Key Features:** High-fidelity visual cards for heritage textiles and jewelry, inventory status tracking (In Stock, Reserved, Out of Stock), and archival categorization.

### 4. Analytics & Intelligence
**Data-Driven Luxury**
- **Purpose:** Deep-dive reporting on customer demographics and collection performance.
- **Key Features:** Interactive sales performance charts, collection popularity heatmaps, and AI-driven strategic insights.

## Technical Specifications
- **Framework:** HTML5 / CSS3 (Tailwind-ready).
- **Responsive:** Optimized for Desktop (1440px+).
- **Interactive:** CSS Transitions for hover states, JS-ready DOM structure for data binding.
